# مرحله ۵: انتشار ایمن و قابل‌بازتولید PatchGuard در GitHub

مقصد این بسته:
`https://github.com/pooryaamirniya/DNS_Project_G11.git`

این بسته **خود پروژه را شامل نمی‌شود**؛ از فایل‌های *نسخه نهایی موجود روی WSL شما* استفاده می‌کند تا اصلاحات انجام‌شده بعد از نصب بسته‌های قبلی از دست نروند. به دسترسی GitHub و اعتبارنامه Git روی دستگاه خودتان نیاز دارد.

## نصب

فایل ZIP این مرحله را در Downloads قرار دهید. از پوشه ریشه `PatchGuard_Project1`:

```bash
cd /mnt/c/Users/poory/Downloads/PatchGuard_Project1
python3 -m zipfile -e ../PatchGuard_GitHub_Stage5.zip .
python3 tools/publish_github.py
```

اسکریپت گزارش‌های ذخیره‌شده ۶/۶ و ۹/۹ را بررسی می‌کند، Quality Gate را در حالت strict دوباره اجرا می‌کند، مخزن را در یک پوشه موقت clone می‌کند، فایل‌های سورس، نسخه‌های target، تنظیمات، تست‌ها، workflowها، مستندات و شواهد لازم را کپی و commit و push می‌کند.

* `git push --force` هرگز اجرا نمی‌شود.
* فایل‌های دیگر از مخزن مقصد حذف نمی‌شوند.
* باینری‌های کامپایل‌شده، فایل‌های cache، فایل‌های محرمانه رایج و خروجی‌های موقت آپلود نمی‌شوند.
* گزارش‌های CI، آزمون‌های blind و Quality Gate و بسته‌های بازتولید (به‌جز باینری‌های build) وارد مخزن می‌شوند.
* اگر نام فایل‌ها با محتویات فعلی مخزن تداخل داشته باشند، محتوای همان مسیر به‌روز می‌شود؛ برای README غیرمرتبط حفاظت اضافه وجود دارد. برای پروژه‌ای که قبلاً محتوا دارد، خروجی `git status` را بررسی کنید.
* کدهای آسیب‌پذیر موجود در مخزن **صرفاً اهداف آموزشی و آزمایشی** هستند و نباید در محصول واقعی استفاده شوند.

## بررسی اختیاری بدون Push

```bash
python3 tools/publish_github.py --dry-run
```

## احراز هویت

اگر GitHub از شما credential خواست، از Git Credential Manager/SSH یا `gh auth login` استفاده کنید. **پسورد حساب GitHub برای HTTPS Git قابل استفاده نیست** و لازم نیست توکن را داخل کد یا چت وارد کنید.

## بررسی موفقیت

بعد از پیام `PUBLISHED` صفحه مخزن را باز کنید. سپس از تب Actions، workflow با نام **PatchGuard Full Quality Gate** را بررسی کنید. موفقیت محلی، موفقیت Actions را تضمین نمی‌کند؛ در صورت قرمز شدن workflow گزارش لاگ GitHub Actions باید بررسی شود.

بخش‌های `docs/TEAM_CONTRIBUTIONS_TEMPLATE_FA.md` را بر اساس *مشارکت واقعی* هر فرد تکمیل کنید. برای تأیید استاد و مدارک دفاع هیچ ادعایی در این بسته نشده است.
